# Per capita sales of alcohol for use in upshifting procedure from MESAS data on alcohol sales in Scotland.

Code to generate these data is in the "data-raw" folder of the hseclean
package. The years data used is 2008 - 2019. For Scotland, population
counts were obtained from National Records Scotland.

## Usage

``` r
per_capita_alc_for_upshift_scotland
```

## Format

A data table

## Source

MESAS data on alcohol sales in Scotland:
https://www.publichealthscotland.scot/publications/mesas-monitoring-report-2022/
