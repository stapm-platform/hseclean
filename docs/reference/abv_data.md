# Alcohol content assumptions

These are the expected percentages of alcohol that each beverage
contains (alcohol by volume, ABV). We use separate values for normal
beer (4.4%), strong beer (8.4%), spirits (38%), sherry (17%), wine
(12.5%), and alcopops (4.5%).

## Usage

``` r
abv_data
```

## Format

A data table

## Source

Natcen assumptions supplemented with market research data and figures
from academic publications.
